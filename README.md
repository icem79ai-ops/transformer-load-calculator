เครื่องมือคำนวณโหลดหม้อแปลงและวงจรแรงต่ำสำหรับโครงการที่อยู่อาศัย กรณีขยายเขตระบบไฟฟ้า — ใช้ได้ฟรีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ไม่ต้องเชื่อมต่ออินเทอร์เน็ต (เปิดไฟล์ `index.html` ได้โดยตรง)

## ความสามารถ

- **โหมด A — ติดตั้งหม้อแปลงใหม่:** เลือกประเภทการติดตั้ง (แขวนเสาเดียว / นั่งร้าน) ระบบแนะนำขนาดหม้อแปลงที่เล็กที่สุดที่โหลดไม่เกินเกณฑ์ที่ตั้ง หรือเลือกขนาดเอง
- **โหมด B — เพิ่มโหลดในหม้อแปลงเดิม:** กรอกโหลดเดิมเป็น kVA ต่อวงจร ระบบรวมโหลด คิดเป็นเปอร์เซ็นต์เทียบหม้อแปลงเดิม และแนะนำขนาดเมื่อต้องอัปเกรด
- **วงจรแรงต่ำ:** เลือกสายเมน THW-A (50 / 95 ตร.มม.), เพิ่มมิเตอร์หลายขนาดต่อวงจรได้อิสระ แจ้งเตือนสีแดงเมื่อกระแสเกินพิกัดสาย
- **สรุปรายวงจร:** แสดงขนาดและจำนวนมิเตอร์ โหลดเดิม / โหลดเพิ่ม / โหลดรวม และกระแสเทียบพิกัดสายไฟ
- ทำงานแบบ Offline — ไฟล์เดียว HTML/CSS/JS ไม่มี dependency ภายนอก

## โครงสร้างไฟล์

```
index.html   — โครงสร้างหน้าเว็บ (2 หน้าจอ: กรอกข้อมูล / ผลลัพธ์)
app.js       — ฐานข้อมูล + ตรรกะการคำนวณทั้งหมด
style.css    — รูปแบบ/ธีม
```
